## API
<!-- 会生成api表格 -->
| 属性 | 类型                   | 默认值   | 必填 | 说明 |
| ---- | ---------------------- | -------- | ---- | ---- |
| labelText | `string` | `placeholder` |  true  | 输入框placeholder |
| InputType | `string` | `text` |  true  | 输入框类型 |
| required | `boolean` | `false` |  true  | 输入框是否开启必填校验 |
| maxWidth | `string\|number` | `600` |  true  | 输入框长度 |
